# TownDetail

Town details, in the context of address.

## Attributes

| Label | Type | Multiplicity | Comment |
|-------|------|--------------|---------|
| code | String | 0..1 | Town code. |
| country | String | 0..1 | Name of the country. |
| name | String | 0..1 | Town name. |
| section | String | 0..1 | Town section. For example, it is common for there to be 36 sections per township. |
| stateOrProvince | String | 0..1 | Name of the state or province. |
