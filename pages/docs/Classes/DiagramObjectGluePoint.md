# DiagramObjectGluePoint

This is used for grouping diagram object points from different diagram objects that are considered to be glued together in a diagram even if they are not at the exact same coordinates.

## Attributes

| Label | Type | Multiplicity | Comment |
|-------|------|--------------|---------|
| DiagramObjectPoints | [DiagramObjectPoint](DiagramObjectPoint.md) | 2..n | A diagram object glue point is associated with 2 or more object points that are considered to be 'glued' together. |
